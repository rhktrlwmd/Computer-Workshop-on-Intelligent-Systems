# Компьютерный практикум по интеллектуальным системам

Направление подготовки: **02.03.02**.

Репозиторий содержит практические работы по дисциплине. Каждая работа хранится в отдельной папке вместе с исходным кодом, инструкцией запуска и материалами для защиты.

## Практические работы

| Папка | Тема | Содержание |
|---|---|---|
| [01_rules_practicum](01_rules_practicum/) | Представление знаний в виде правил | База знаний для подбора книг, прямой и обратный вывод, разрешение конфликтов, CLIPS |

## Первая работа

Все команды для первой работы выполняются из её папки:

```bash
cd 01_rules_practicum
python3 main.py --demo
```
