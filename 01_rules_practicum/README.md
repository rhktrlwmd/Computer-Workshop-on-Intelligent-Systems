# Практикум по системам правил

Дисциплина: «Компьютерный практикум по интеллектуальным системам (02.03.02)».
Вариант 3: выбор книги на основе предпочтений читателя.

В одном проекте выполнены три упражнения: база знаний, прямой и обратный вывод,
разрешение конфликтов и запуск той же базы в CLIPS.

## Что открыть

- `Отчёт.docx` — отчёт для преподавателя.
- `Отчёт.md` — тот же текст в открытом текстовом формате.
- `Защита.md` — требования по скриншотам, объяснение простыми словами, сценарий показа и вопросы с ответами.
- `demo_output.txt` — сохранённый запуск всех девяти примеров с CLIPS.
- `test_results.txt` — протокол 22 успешно выполненных тестов без пропусков.

## Запуск без установки библиотек

Нужен Python 3.10 или новее. Проверено с Python 3.12.14.
При работе с GitHub откройте терминал в папке `01_rules_practicum`.
Из корня репозитория перейдите в неё командой `cd 01_rules_practicum`.
В исходном архиве эта папка называлась `rules_practicum`.

```bash
python3 main.py --rules
python3 main.py --demo
python3 main.py --case 1 --verbose
python3 main.py --interactive --goal martian
```

В Windows используйте `py` вместо `python3`, если команда `python3` недоступна.
Без аргументов программа также запускает все примеры.

## Полный запуск с фреймворком

macOS / Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py --demo --framework
python -m unittest -v
```

Windows, PowerShell или командная строка, без активации:

```text
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py --demo --framework
.venv\Scripts\python.exe -m unittest -v
```

Установка требует интернета. Далее программа работает локально.
При отсутствии clipspy пять тестов CLIPS будут пропущены. Для полного выполнения
третьего упражнения установите зависимость и убедитесь, что в конце тестов нет `skipped`.

## Короткая демонстрация на защите

```bash
python main.py --rules
python main.py --case 1 --framework --verbose
python main.py --case 3 --framework
python main.py --case 5 --framework
python main.py --case 8 --framework
python -m unittest -v
```

Пример 1 показывает приоритет, 3 — специфичность, 5 — порядок при равенстве
и различие между доказанным кандидатом и окончательным выбором, 8 — недоказанную цель.

## Файлы программы

| Файл | Назначение |
|---|---|
| `knowledge.py` | 7 входных признаков, 6 книг, 12 правил, стратегия выбора |
| `engine.py` | Прямой и рекурсивный обратный вывод, дерево доказательства |
| `framework.py` | Генерация и запуск правил CLIPS, чтение настоящей повестки CLIPS |
| `books.clp` | Полная база знаний на языке CLIPS |
| `examples.py` | Девять примеров с ожидаемыми ответами |
| `main.py` | Показ правил, демонстрация, интерактивные вопросы |
| `test_system.py` | 22 теста, полный перебор 128 наборов входных признаков |
| `requirements.txt` | Зависимость clipspy 1.0.6 |

После изменения `knowledge.py` выполните `python framework.py`, затем тесты:
файл CLIPS должен соответствовать обновлённой базе знаний.

## Границы модели

Правила рекомендаций и приоритеты заданы как учебные экспертные предположения.
Программа не обучается на данных. В ней нет запретов, отрицательных фактов,
оценки вероятности, удаления фактов или обработки нескольких читателей в одной сессии.
Ответ «нет» не добавляет положительный признак. Недоказанная цель означает,
что для неё не найдено доказательства в данной базе, а не что книга точно не подходит.

Сведения об API фреймворка: [официальная документация clipspy](https://clipspy.readthedocs.io/en/latest/).
