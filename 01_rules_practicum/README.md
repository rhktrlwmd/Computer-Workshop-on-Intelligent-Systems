# Подбор книг по правилам

Первая работа по дисциплине «Компьютерный практикум по интеллектуальным системам (02.03.02)». Вариант 3.

## Три основных файла

- **main.py** — вся программа: факты, 12 правил, прямой и обратный вывод на Python, запуск обоих направлений через CLIPS и 9 примеров.
- **backward.clp** — рекурсивный алгоритм обратного поиска на языке CLIPS.
- **README.md** — эта инструкция.

В папке **materials** лежат дополнительные материалы: отчёт Word, пояснения для защиты, автоматические проверки и сохранённые результаты запусков.

## Запуск

Откройте терминал в папке `01_rules_practicum`. Нужен Python 3.10 или новее.

```bash
python3 main.py --rules
python3 main.py --case 1 --verbose
python3 main.py --demo
python3 main.py --interactive --goal martian
```

Для версий с CLIPS установите библиотеку в Python-окружение:

```bash
python -m pip install clipspy==1.0.6
python main.py --case 1 --framework --verbose
python main.py --demo --framework
```

Если окружение ещё не создано, сначала выполните `python3 -m venv .venv` и `source .venv/bin/activate` (macOS/Linux). В Windows используйте `.venv\Scripts\python.exe` вместо `python` без активации.

Все 30 автоматических проверок запускаются одной командой:

```bash
python main.py --test
```

При отсутствии clipspy 13 проверок CLIPS пропускаются. Для полного показа нужен результат без пропусков.

## Что показать преподавателю

Откройте **main.py** и находите нужный участок поиском по имени:

| Что показать | Где искать |
|---|---|
| Факты и 12 правил | `INPUTS`, `BOOKS`, `RULES` |
| Разрешение конфликтов | `rank`, `ordered`, `select_book` |
| Прямой вывод без фреймворка | `def forward` |
| Обратный вывод без фреймворка | `def backward` и вложенная `prove` |
| Прямой вывод CLIPS | `def run_clips`, правила создаются в `clips_constructs` |
| Обратный вывод CLIPS | `def run_clips_backward`, а сам поиск — `prove-goal` в **backward.clp** |
| Девять проверочных ситуаций | `EXAMPLES` |

Прямой вывод выбирает применимое правило по приоритету, затем по количеству условий, затем по порядку в базе. Он получает все достижимые факты; отдельный этап выбирает одну книгу. Обратный вывод проверяет конкретную цель по исходным фактам и правилам, пробуя альтернативы при неудаче.

Правила CLIPS для прямого вывода создаются из `RULES` в памяти: отдельный файл `books.clp` не требуется. Обратный поиск явно реализован рекурсивной процедурой на языке CLIPS. Python передаёт ей данные и читает дерево доказательства.

Короткий показ: пример 1 — приоритет и оба направления вывода, пример 3 — специфичность, пример 5 — порядок при равенстве, пример 8 — недоказанная цель. Добавьте `--framework`, чтобы показать также CLIPS.
